# CAPS S&C

Combat Athlete Performance System.

## Run

```bash
npm install
npm start
```

Open the project in Expo Go from the Expo CLI prompt.

## Structure

```text
src/
  components/   Shared UI pieces for the shell.
  navigation/   Route names and the small navigation state container.
  screens/      Current app screens.
  theme/        Design tokens shared by the UI.
```
