- Reviewer found Done-during-momentum could commit old state; root added scroll-preview refs used by Done. Root also corrected the RN 0.88 ScrollView ref type and removed `StyleSheet.absoluteFillObject` usage reported by typecheck. Native momentum/tap ordering remains a device QA item.
- `NutritionChrome.tsx` reuses the common header instead of its duplicate. `NutritionFooter` counts logical, non-exiting stack entries; first layer Cancel and nested layers Back call `pop`. Existing non-navigation actions remain present. `closeToRoot` exits every Nutrition layer while persisted drafts remain available; existing explicit destructive discard actions remain separate.
- Strength X uses the full-draft discard guard even from exercise/emphasis children. Exercise Back retains the local exercise discard behavior. Skill builder uses its existing draft guard.
- Conditioning depth includes a presented editor in addition to stack entries: main → editor is Cancel; saved → editor and editor → station/log/emphasis are Back. Local station/manual-log guards protect those separate drafts; branch close also protects the owning workout. Confirm dialogs dismiss before invoking destinations, allowing a second parent guard when needed. Live recording exits retain recording state.
- `Screen.tsx`, `Screens.tsx`, `AppNavigator.tsx`: sidebar routes use the shared header/footer, hide the duplicate global header, and return to the remembered main tab. Account/Athlete register their close guard for hardware Back. The five main-screen title cards remain intact.

Nutrition forms retain `keyboardShouldPersistTaps="handled"`; page bodies flex above footer.
