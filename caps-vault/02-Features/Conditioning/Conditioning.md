## Compact parameters (24 November 2026)

`CreateConditioningSessionScreen.tsx` removes Workout Identity, title presets and the phase-sequence preview. Time Interval has one Parameters card with direct Work (s), Rest (s), Intervals, Rounds, Rest between rounds (s) and Target RPE text boxes. There are no increment/decrement buttons or preset strips. New Time Interval drafts receive the required format title implicitly; existing saved titles/notes are retained. Other structured editors retain plain title/notes inputs and now use the same direct numeric fields rather than steppers; sprint distance/elevation retain canonical metre conversion.

The Estimated Focus button immediately below Parameters reuses the same `EstimatedFocusButton` as Strength. Conditioning labels/colors come from its own six-index heuristic and remain inside this discipline. `estimateSnapshotEmphasis` in `src/conditioning/emphasis.ts` centralizes the existing snapshot projection for the preview button and detail screen; it changes no model weights or stored estimates. Missing/invalid input shows insufficient evidence, never invented duration/RPE.

Raw text continues to live in the Conditioning workspace draft; clearing a required rest/count/duration now fails validation rather than silently becoming zero. Explicit zero rest remains valid. Existing positive-integer/RPE/2000-occurrence guards still apply. A synchronous submission lock prevents double saves/starts, preserves drafts on failure, and blocks editor Back/X while saving. Station and focus visits retain the parent draft.

There is no Conditioning schema/table change. Template saves, planned-session snapshots, recordings and completed logs retain their established separate relational ownership and IDs; a title default only satisfies the existing required template/snapshot title. Current integration schema v11 belongs to the separate Skills reps feature. `npm run verify:conditioning` passed with direct-input blank-vs-zero, RPE/occurrence limits and shared emphasis-projection regression coverage. Android verified all four chooser choices and Free/Time Interval navigation, compact fields, required interval RPE validation/focus updates and keyboard-accessible actions after the shared navigator correction. Native enlarged font, iOS and live GPS/timer execution remain unrun. See [[2026-11-24 Compact Logging Android QA]].
